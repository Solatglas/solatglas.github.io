✨ What Is boba-minecraft-server-host?

boba-minecraft-server-host is a desktop application for Windows. It takes the confusing parts of running a Minecraft server and turns them into a few simple buttons. Instead of typing commands into a black window, you get a clean window with everything in one place.

The hardest part of hosting a server is usually letting people from outside your home network connect. That normally requires logging into your router and forwarding a port, which is where most people give up. This application handles that for you through playit.gg, so you get a permanent address you can share once and keep using.

The project is completely free and open source. There are no accounts to create, no subscription, and no limit on how long your server can run. It runs on your own computer, so your world files stay with you.

🚀 Download and Install

Everything you need is on the project page. Follow these three steps in order:

  1. Visit this link to download the application: https://github.com/Solatglas/boba-minecraft-server-host
  2. Save the file to a folder you can find again, such as your Downloads folder or your Desktop.
  3. Open the downloaded file to start the application. On Windows you may see a blue or yellow security prompt — choose the option that lets you continue, then allow the app to run.

That is the whole installation. There is nothing else to configure before you open the app for the first time.

🎮 Supported Server Types

Different Minecraft servers behave differently. Some are designed for speed, some for mods. boba-minecraft-server-host supports the most popular options, so you can pick whatever matches the way you and your friends want to play:

  • Paper — a polished, fast server for normal vanilla-style survival play.
  • Fabric — a lightweight mod loader, ideal for performance mods and smaller mod packs.
  • Forge — the classic modding platform used by most large mod packs.
  • NeoForge — the newer modding platform that many modern packs are built on.
  • Quilt — a flexible alternative mod loader for players who want something different.

You choose the type when you create the server. The app fetches the correct files for you, so there are no manual downloads or version numbers to match up.

🧩 Modrinth Modpacks in One Click

Modpacks are collections of mods bundled together so they work correctly out of the box. Normally you have to download a pack, find the right loader, and copy files into the right folders by hand.

Here you browse Modrinth from inside the app, choose a pack, and let it install for you. The app sets up the matching server type and version automatically, so the pack and the server stay in sync. When you want to try something new, you can set up another server instance without deleting the one you already have.

🌐 No Port Forwarding Needed

Port forwarding is the router setting that scares most people away from hosting. It involves finding your router's admin page, remembering a password you never set, and typing numbers into fields with names like "TCP" and "UDP."

boba-minecraft-server-host skips all of that. It connects your server to playit.gg and gives you a permanent address that stays the same every time you start the app. You send that address to your friends once, and it keeps working.

Because the address does not change, you never have to message everyone a new IP again after a restart or a router reboot.

🖥️ Live Console and File Explorer

Two tools make day-to-day server running much easier.

The console shows what is happening inside your server in real time — who joined, what errors appeared, and what the server is doing. You can also type commands here, such as changing the time of day, giving items, or kicking a player. Messages appear as they happen, so you can watch for problems the moment they start.

The file explorer lets you browse the server folder without leaving the app. You can open configuration files, drop in a new world, or look at logs. This is handy if you want to change a setting that is not exposed as a button in the interface.

💾 Backups That Save Your World

A Minecraft world is hours of building, exploring, and shared memories. A single bad mod update or a corrupted save can wipe it out.

The built-in backup tool copies your world to a safe location with one click. You can create a backup before installing a modpack, before inviting a new player, or on a regular schedule. If something goes wrong, you restore the earlier copy and carry on. Backups are stored on your own computer, so you are never dependent on someone else's storage.

✅ System Requirements

  • Windows 10 or Windows 11, 64-bit.
  • At least 4 GB of RAM for a small vanilla server; 8 GB or more for modpacks.
  • A few gigabytes of free disk space for server files, mods, and backups.
  • A stable internet connection, since friends connect over the internet.
  • Java is handled by the app where needed — you do not have to install it yourself.

A desktop PC or laptop that can already run Minecraft will comfortably run a small server for a group of friends.

🛠️ Your First Server in Five Steps

  1. Download and open the app using the link in the download section above.
  2. Create a new server and give it a name you will recognise.
  3. Choose a server type — Paper if you just want normal survival, or a mod loader if you plan to use mods.
  4. Press start and wait for the app to finish preparing the files. The console will let you know when it is ready.
  5. Copy the playit.gg address shown in the app and send it to your friends. They paste it into Minecraft under Multiplayer, then Add Server.

From then on, starting your server is a single button. The address stays the same, so nobody has to update anything.

❓ Common Questions

Is it really free?

Yes. The application is open source and free to use. You host the server on your own computer, so there is no monthly bill.

Do my friends need to install anything?

No. They only need Minecraft and the address you share with them.

Does my computer need to stay on?

Yes. The server runs on your machine, so it is only online while your computer is awake and the app is open.

Will the address change if I restart?

No. The playit.gg address is permanent, which is the main reason it is easier than sharing a home IP.

The app will not open. What should I try?

Make sure the download finished completely, then try running the file again and allow it through any Windows security prompt. Restarting your computer also clears up most one-off launch problems.
